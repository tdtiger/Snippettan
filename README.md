# すにぺったん
コードスニペットをローカルで管理するためのGUIアプリケーションです。

クリックするだけで簡単にスニペットをコピー。
あなたのコーディングをお助けします。

## 主な機能
- スニペットの追加
- スニペットの編集
- スニペットの削除
- JSONによるデータ保存
- タグ・タイトルでの検索
- 言語フィルタ
- シンタックスハイライト（性能はお察し）
- お気に入り登録
- ダークテーマ切り替え

## 使用技術
- Python
- PyQt6

## 起動方法
本ディレクトリの階層構造を維持したまま、
```bash
pip install PyQt6 (インストール済みの場合はスキップ可)

python main.py
```
